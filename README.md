# Inspector de calidad: Valor p

Videojuego educativo de una sola página, en español y sin dependencias. El jugador revisa ocho lotes de un almacén, compara el valor p con α = 0.05 y decide si rechaza H₀ o deja pasar el lote.

## Cómo abrirlo

Abre `index.html` en un navegador. No requiere instalación ni conexión a internet.

## Qué enseña

- H₀: el lote cumple la especificación; H₁: el lote no la cumple.
- Si p ≤ α, se rechaza H₀. Si p > α, no se rechaza H₀.
- No rechazar H₀ no demuestra que sea verdadera.
- Rechazar una H₀ verdadera produce un error tipo I; no rechazar una H₀ falsa produce un error tipo II.
- El valor p describe los datos bajo H₀; no es la probabilidad de que un lote esté defectuoso.

Los informes y estados reales son escenarios simulados para practicar decisiones y visualizar los errores posibles. Cada acierto suma 100 puntos y cada lote bueno detenido o lote defectuoso liberado resta 100.
